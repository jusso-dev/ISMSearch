# Design

## Theme

Security practitioners compare controls on a large monitor during focused review work, often alongside documentation and ticketing systems in a normal office or home-office environment. Use a light, paper-like workspace with tinted neutral surfaces, quiet contrast and a compact command surface.

## Color

Use OKLCH tokens. The strategy is restrained product UI: warm off-white neutrals, ink-like text, eucalyptus green as the primary action/selection color and amber/coral only for comparison states. Avoid pure black, pure white, navy-and-gold, neon green and single-hue blue dashboard palettes.

## Typography

Use a system UI stack for all product text. Keep labels compact, headings confident but not oversized, and prose capped to readable line lengths. Control identifiers should use tabular number settings where practical.

## Components

Primary surfaces are search panels, tabbed result regions, inline comparison rows, answer citations and metadata chips. Cards are allowed for individual controls and answer evidence, but page sections should stay unframed. Buttons use icon plus text where the action benefits from recognition.

## Layout

Desktop uses a workbench layout: a persistent query/comparison rail and a larger results/detail region. Mobile collapses to a single-column task flow with filters above results. Fixed-format UI such as chips, tabs, icon buttons and counters must have stable dimensions.

## Motion

Use short 150-220ms transitions for hover, focus, selected state and result reveal. Motion communicates state only. Respect reduced motion.
